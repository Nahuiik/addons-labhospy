Disable Product Update Quantity

Purpose: This module restricts the manual update of product quantities in Odoo. It hides the Update Quantity button from product forms and prevents quantity creation from the On Hand button for users without the required access rights. Only users with Onhand Quantity access rights can update or create product quantities.

Key Features

  • Hide Update Quantity Button Prevents unauthorized users from seeing the Update Quantity button on product forms.
  • Restrict Quantity Creation Disables quantity creation via the On Hand button for unauthorized users.
  • Access-Controlled Updates Only users with Onhand Quantity access rights can update product quantities.
  • Controlled Visibility Shows Update Quantity and Create buttons only to authorized users.
  • Better Inventory Control Helps maintain accurate stock data by restricting manual edits.

How It Works:

After installing the module:

  • Users without Onhand Quantity rights cannot see the Update Quantity button.
  • On Hand button will not allow creating quantities for unauthorized users.
  • Users with the correct rights can update or create quantities as needed.

Setup Instructions:

1. Go to Settings > Users & Companies → Users
2. Edit the user and assign Onhand Quantity access rights
3. Save and refresh the page to see the changes

Benefits:

Prevents unauthorized stock adjustments
Reduces manual errors in inventory
Improves stock accuracy and accountability
