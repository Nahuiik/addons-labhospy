Municipios y Departamentos de Honduras

Localización geográfica completa para Honduras en Odoo

Versión: 18.0.1.0.1

Características Principales

Localización Geográfica Completa

  • Lista completa de Municipios y Departamentoss de Honduras
  • Interfaz adaptada a la terminología local (Municipios en lugar de Ciudad, Departamentos en lugar de Estado)
  • Oculta automáticamente el campo de código postal para direcciones de Honduras
  • Filtrado inteligente de Municipios según el Departamento seleccionado
  • Honduras configurado como país predeterminado para nuevos contactos
  • Moneda HNL configurada por defecto para Honduras

Mejoras de Usabilidad

  • Selección automática del primer Municipio al cambiar de Departamentos
  • Priorización de Municipios de Honduras en las listas desplegables
  • Valores predeterminados para agilizar la creación de contactos
  • Menú dedicado para administrar la lista de Departamentos
  • Interfaz intuitiva con etiquetas adaptadas al contexto hondureño

Funcionamiento

Una vez instalado, el módulo cambia automáticamente las etiquetas, establece Honduras como país predeterminado, y proporciona una experiencia de usuario optimizada para la gestión de direcciones salvadoreñas.

  • Cambia automáticamente las etiquetas de "Ciudad" a "Municipio" y "Estado" a "Departamentos"
  • Establece Honduras como país predeterminado en los formularios de contacto
  • Oculta el campo de código postal cuando se selecciona Honduras como país
  • Proporciona una lista filtrada de Municipios basada en el Departamentos seleccionado

Instalación y Uso

1. Descargue el módulo y colóquelo en la carpeta de addons de Odoo
2. Actualice la lista de módulos
3. Busque e instale el módulo "Municipios / Departamentos de Honduras"
4. Acceda a la lista completa de Municipios desde el menú Contactos > Configuración > Localización > Ciudades
