Tree Header Sticky


This module enhances the Odoo list view functionality by making the header row sticky. When scrolling vertically through long lists, the header remains fixed at the top, significantly improving the user experience when working with large datasets.

Key features include:

  • Fixed Headers: Keep column headers visible while scrolling vertically
  • Enhanced Navigation: Easy column reference in long list views
  • Universal Compatibility: Works with all Odoo list views
  • Zero Configuration: Works immediately after installation
  • Modern Interface: Clean and responsive design

Usage

The module works automatically after installation:

  1. Install the module
  2. Open any list view in Odoo
  3. Scroll vertically to see the header row remain fixed at the top
  4. Enjoy improved navigation in long lists

Benefits

  • Improved Efficiency: Quick reference to column names in long lists
  • Better Navigation: No need to scroll back to check column headers
  • Enhanced Readability: Always know which column contains what data
  • Universal Application: Works with all list views automatically
  • Performance Optimized: Minimal impact on system resources
