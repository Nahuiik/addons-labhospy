Фіксований заголовок списку


Цей модуль покращує функціональність списків Odoo, фіксуючи рядок заголовків. При вертикальному прокручуванні довгих списків заголовки залишаються у верхній частині, що значно покращує користувацький досвід при роботі з великими наборами даних.

Основні можливості:

  • Фіксовані заголовки: Заголовки стовпців залишаються видимими при прокручуванні
  • Покращена навігація: Легкий перегляд назв стовпців у довгих списках
  • Універсальна сумісність: Працює з усіма списками Odoo
  • Нульова конфігурація: Працює одразу після встановлення
  • Сучасний інтерфейс: Чистий та адаптивний дизайн

Використання

Модуль працює автоматично після встановлення:

  1. Встановіть модуль
  2. Відкрийте будь-який список в Odoo
  3. Прокрутіть вертикально, щоб побачити, як заголовки залишаються у верхній частині
  4. Насолоджуйтесь покращеною навігацією у довгих списках

Переваги

  • Підвищена ефективність: Швидкий доступ до назв стовпців у довгих списках
  • Краща навігація: Не потрібно прокручувати назад для перевірки заголовків
  • Покращена читабельність: Завжди видно, які дані містяться в кожному стовпці
  • Універсальне застосування: Працює з усіма списками автоматично
  • Оптимізована продуктивність: Мінімальний вплив на системні ресурси
