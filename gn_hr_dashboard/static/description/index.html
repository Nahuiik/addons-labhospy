GN HR Dashboard

Dashboard unificado de Recursos Humanos: acceso rápido a informes de empleados (Excel/wizards) y, para perfiles autorizados, una vista regional con KPIs y gráficos multi‑compañía (headcount, nómina, rotación, ausencias, tendencias, etc.).

  • Pestaña Informes: categorías registradas por otros módulos (p. ej. localización de nómina) y búsqueda de informes.
  • Pestaña Vista regional: datos agregados vía JSON-RPC respetando las compañías del usuario y permisos de RRHH.
  • Integración opcional con incidencias de asistencia y acciones de gn_hr_intercompany cuando estén instalados.
