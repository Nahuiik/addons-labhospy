Branch Management

Multiple Branch(Unit) Operation Setup for All Applications Odoo/OpenERP.

Features

  • You can add multiple branches inside company.
  • Branch user can only access records of its assigned branch.
  • Branch manager can access records of all branches.
  • Branch wise accounting transactions are generated but company has single chart of accounts for all branches.
