1. Introducción

El módulo de Localización Laboral Honduras para Odoo 19 proporciona una solución completa para la gestión de nómina según la legislación laboral hondureña. Este módulo automatiza los cálculos de deducciones legales y beneficios, facilitando el cumplimiento normativo.

Características Principales

  • IHSS (Instituto Hondureño de Seguridad Social): Cálculo automático de aportes IVM y EM con techos configurables
  • RAP (Régimen de Aportaciones Privadas): Gestión de FOVIIF y FRL
  • ISR (Impuesto sobre la Renta): Cálculo de retenciones con tablas progresivas
  • 13° y 14° Mes: Cálculo automático de beneficios anuales
  • Gestión de Contratos: Historial completo de versiones de contratos (adaptado a Odoo 19)
  • Importación Masiva: Wizard para importar empleados desde Excel
  • Conceptos Recurrentes: Gestión de ingresos y deducciones recurrentes
Nota Importante: En Odoo 19, los contratos de empleados se gestionan a través del historial de contratos (hr.employee.contract.history) en lugar del modelo separado hr.contract. Este módulo está adaptado para trabajar con esta nueva estructura.

2. Configuración Inicial

Antes de comenzar a procesar nóminas, es necesario configurar los parámetros legales para el año en curso. Esta configuración debe realizarse una vez por año o cuando cambien los parámetros oficiales.

2.1. Configuración IHSS

Menú: Honduras Payroll → Configuration → IHSS Settings

1 Crear nueva configuración: Haga clic en "Crear" y complete los siguientes campos:
Campo Descripción Ejemplo (2025)
Año Año fiscal para el cual aplica esta configuración 2025
Compañía Compañía para la cual aplica esta configuración Mi Empresa S.A.
IVM Techo Mensual Techo mensual para cálculo de IVM 11,903.13
IVM Tasa Empleador Porcentaje que paga el empleador 3.5%
IVM Tasa Empleado Porcentaje que se descuenta al empleado 2.5%
EM Techo Mensual Techo mensual para cálculo de EM 11,903.13
EM Tasa Empleador Porcentaje que paga el empleador 1.0%
EM Tasa Empleado Porcentaje que se descuenta al empleado 1.0%
2 Configurar reglas de aplicación: En la pestaña "Application Rules", seleccione en qué quincenas se aplicará la deducción:
  • Aplicar en Primera Quincena: Si se marca, la deducción se aplica en la primera quincena del mes
  • Aplicar en Segunda Quincena: Si se marca, la deducción se aplica en la segunda quincena
3 Configurar cuentas contables: En la pestaña "Accounting", asigne las cuentas contables para:
  • IVM Empleado (deducción)
  • IVM Empleador (aporte patronal)
  • EM Empleado (deducción)
  • EM Empleador (aporte patronal)
4 Validar configuración: Haga clic en el botón "Validate" para activar la configuración. Solo puede haber una configuración validada por año y compañía.
Información: El sistema calcula automáticamente el techo del período usando la regla estándar 30/360. Por ejemplo, para una quincena (15 días): TechoQuincena = TechoMensual × (15/30).

2.2. Configuración RAP

Menú: Honduras Payroll → Configuration → RAP Settings

1 Crear nueva configuración: Complete los campos básicos (Año, Compañía).
2 Configurar FOVIIF: En la pestaña "FOVIIF Parameters":
  • Piso Mensual: Monto sobre el cual se calcula FOVIIF (excede el techo IVM)
  • Tasa Empleado: 1.5%
  • Tasa Empleador: 1.5%
3 Configurar FRL: En la pestaña "FRL Parameters":
  • Salario Mínimo Escala Alta: Salario mínimo en su escala más alta
  • Techo FRL Mensual: Se calcula automáticamente (3× salario mínimo)
  • Tasa Empleador: 4.0%
4 Validar: Haga clic en "Validate" para activar.

2.3. Configuración ISR

Menú: Honduras Payroll → Configuration → ISR Tables

1 Crear nueva tabla: Complete Año, Periodicidad (semanal/quincenal/mensual/anual) y Compañía.
2 Configurar monto exento: Ingrese el monto anual exento (ej: 228,324.32 para 2026).
3 Agregar tramos de impuestos: En la sección "Tax Brackets", agregue cada tramo:
Tramo Monto Mínimo Monto Máximo Tasa Impuesto Base
1 0.00 228,324.32 0% 0.00
2 228,324.33 348,154.10 15% 0.00
3 348,154.11 809,660.75 20% 17,974.47
4 809,660.76 0.00 (ilimitado) 25% 110,275.80
4 Configurar deducción servicios médicos: Ingrese el monto anual (ej: 40,000.00 para 2026).
5 Validar: Haga clic en "Validate" para activar la tabla.

2.4. Configuración de Reglas Salariales

Menú: Nómina → Configuración → Reglas Salariales

Para cada regla salarial, en la pestaña "Honduras Configuration", marque las casillas correspondientes:

Campo Descripción Ejemplo
IHSS Base Incluir esta regla en la base de cálculo de IHSS Salario base, horas extra
RAP Base Incluir esta regla en la base de cálculo de RAP Salario base
ISR Base Incluir esta regla en la base gravable de ISR Salario base, horas extra, comisiones, bonos
Computable for Benefits Incluir esta regla en el cálculo de 13° y 14° mes Salario base, horas ordinarias
Periodicity Periodicidad para la cual aplica esta regla Semanal, Quincenal, Mensual, Todas
Year Año específico (0 para todos los años) 2025 o 0
Importante: Los conceptos no salariales (viáticos, reembolsos comprobados) NO deben marcarse como bases de cálculo.

  • El salario debe ser un número mayor a cero

3.2. Configuración de Empleados

En la ficha del empleado, pestaña "Honduras Payroll":

Deducciones

  • Exclude from IHSS: Marcar si el empleado está excluido de deducciones IHSS
  • IHSS Settings: Muestra la configuración activa (solo lectura)
  • Exclude from RAP: Marcar si el empleado está excluido de deducciones RAP
  • RAP Settings: Muestra la configuración activa (solo lectura)
  • Exclude from ISR: Marcar si el empleado está excluido de retenciones ISR

Contrato Actual

Muestra automáticamente el contrato activo según la fecha actual, incluyendo:

  • Salario actual
  • Periodicidad de pago
  • Puesto de trabajo
  • Departamento

3.3. Gestión de Contratos

En Odoo 19, los contratos se gestionan a través del historial de contratos del empleado.

1 Ver historial: En la pestaña "Honduras Payroll" → "Contract History", verá todas las versiones de contratos del empleado.
2 Crear nueva versión: Para crear un nuevo contrato o modificar el existente:
  • Haga clic en "Crear" en la sección "Contract History"
  • Complete los campos:
    • Start Date: Fecha de inicio del contrato
    • End Date: Fecha de fin (dejar vacío para indefinido)
    • Wage: Salario
    • Periodicity: Semanal, Quincenal o Mensual
    • Job Position: Puesto de trabajo
    • Department: Departamento
Nota: El sistema automáticamente determina cuál es el contrato activo comparando la fecha actual con las fechas de inicio y fin de cada versión.

3.4. Conceptos Recurrentes

Los conceptos recurrentes permiten gestionar ingresos y deducciones que se aplican automáticamente en cada nómina.

1 Crear concepto: En la sección "Recurring Concepts" del empleado, haga clic en "Crear".
2 Configurar concepto:
  • Name: Nombre del concepto
  • Type: Income (ingreso) o Deduction (deducción)
  • Amount Type:
    • Fixed: Monto fijo
    • Percentage: Porcentaje de una regla base
  • Amount: Monto fijo o valor del porcentaje
  • Base Rule: Regla salarial base (si es porcentaje)
  • Start Date / End Date: Período de vigencia

Préstamos y Anticipos

Para gestionar préstamos o anticipos:

  1. Marque la casilla "Is Loan/Advance"
  2. Ingrese el Total Amount del préstamo
  3. Ingrese el número de Installments (cuotas)
  4. El sistema calculará automáticamente:
    • Monto por cuota = Total Amount / Installments
    • Saldo pendiente

4. Beneficios Legales

4.1. Décimo Tercer Mes (Aguinaldo)

Menú: Honduras Payroll → Benefits → 13th Month

1 Crear registro: Haga clic en "Crear" y seleccione el empleado y año.
2 Seleccionar método de cálculo:
  • Proportional: Proporcional a días trabajados
    • Requiere: Period Start, Period End, Base Salary, Total Days
    • Fórmula: (Base Salary / Total Days) × Worked Days
  • Fixed: Salario fijo
    • Requiere: Base Salary
    • Fórmula: Base Salary
  • Variable: Promedio de salarios variables
    • Requiere: Average Salary
    • Fórmula: Average Salary
3 Configurar período: Ingrese las fechas de inicio y fin del período trabajado. El sistema calculará automáticamente los días trabajados.
4 Configurar exención ISR: Ingrese el monto exento (hasta 10 salarios mínimos). El excedente será gravable para ISR.
5 Seleccionar mes de pago: Por defecto es diciembre (12), pero puede cambiarse.
6 Marcar como pagado: Una vez procesado el pago en nómina, marque "Paid" y vincule el payslip correspondiente.

4.2. Décimo Cuarto Mes

Menú: Honduras Payroll → Benefits → 14th Month

1 Crear registro: Similar al 13° mes, seleccione empleado y año.
2 Seleccionar método de cálculo:
  • Average: Promedio de salarios ordinarios del período de cálculo
  • Fixed: Salario fijo
  • Sum: Suma de salarios ordinarios del período
3 Configurar período de cálculo: Típicamente el primer semestre del año (enero a junio).
4 Mes de pago: Por defecto es junio (6).
Nota: El sistema calculará automáticamente el promedio o suma desde los payslips del empleado en el período de cálculo especificado.

5. Procesamiento de Nómina - Proceso Completo

Este módulo incluye reglas salariales preconfiguradas que se crean automáticamente al instalar el módulo. A continuación se detalla el proceso completo desde la configuración inicial hasta la generación de la nómina.

5.1. Configuración Inicial (Primera Vez)

1 Configurar IHSS Settings:

Menú: Honduras Payroll → Configuration → IHSS Settings

  1. Crear nueva configuración para el año actual
  2. Completar todos los campos requeridos (año, compañía, techos, tasas)
  3. Configurar cuentas contables en la pestaña "Accounting"
  4. Validar la configuración haciendo clic en "Validate"
Importante: Solo puede haber una configuración validada por año y compañía. Al validar una nueva, la anterior se desactiva automáticamente.
2 Configurar RAP Settings:

Menú: Honduras Payroll → Configuration → RAP Settings

  1. Crear nueva configuración para el año actual
  2. Completar parámetros FOVIIF (piso mensual, tasas empleado/empleador)
  3. Completar parámetros FRL (salario mínimo escala alta, tasa empleador)
  4. Configurar cuentas contables en la pestaña "Accounting"
  5. Validar la configuración
3 Configurar Tablas ISR:

Menú: Honduras Payroll → Configuration → ISR Tables

  1. Crear tabla para cada periodicidad que use (semanal, quincenal, mensual)
  2. Completar año, periodicidad y compañía
  3. Configurar monto exento anual
  4. Agregar todos los tramos de impuestos en la sección "Tax Brackets"
  5. Configurar deducción de servicios médicos
  6. Validar cada tabla
Nota: Si procesa nóminas semanales, quincenales y mensuales, necesitará crear y validar una tabla para cada periodicidad.
4 Verificar Reglas Salariales Preconfiguradas:

Menú: Nómina → Configuración → Reglas Salariales

El módulo crea automáticamente las siguientes reglas salariales:

Código Nombre Tipo Descripción
BASE_IHSS Base para Cálculo IHSS Base Suma todas las reglas marcadas como base IHSS
BASE_RAP Base para Cálculo RAP Base Suma todas las reglas marcadas como base RAP
BASE_ISR Base Imponible ISR Base Suma todas las reglas marcadas como base ISR
IHSS_IVM_EMP IHSS IVM Empleado Deducción Calcula IVM del empleado
IHSS_IVM_EMPLEADOR IHSS IVM Empleador Aporte Patronal Calcula IVM del empleador
IHSS_EM_EMP IHSS EM Empleado Deducción Calcula EM del empleado
IHSS_EM_EMPLEADOR IHSS EM Empleador Aporte Patronal Calcula EM del empleador
RAP_FOVIIF_EMP RAP FOVIIF Empleado Deducción Calcula FOVIIF del empleado
RAP_FOVIIF_EMPLEADOR RAP FOVIIF Empleador Aporte Patronal Calcula FOVIIF del empleador
RAP_FRL_EMPLEADOR RAP FRL Empleador Aporte Patronal Calcula FRL del empleador
ISR_DEDUCCIONES Deducciones ISR Deducción Calcula deducciones exentas y servicios médicos
ISR_RETENCION ISR Retención Deducción Calcula retención de ISR según tabla
✓ Las reglas ya están creadas y configuradas. Solo necesita asegurarse de que estén incluidas en su estructura salarial.
5 Configurar Estructura Salarial:

Menú: Nómina → Configuración → Estructuras Salariales

  1. Crear o editar su estructura salarial
  2. En la sección "Reglas Salariales", agregar las reglas preconfiguradas:
    • Reglas base: BASE_IHSS, BASE_RAP, BASE_ISR
    • Reglas IHSS: IHSS_IVM_EMP, IHSS_IVM_EMPLEADOR, IHSS_EM_EMP, IHSS_EM_EMPLEADOR
    • Reglas RAP: RAP_FOVIIF_EMP, RAP_FOVIIF_EMPLEADOR, RAP_FRL_EMPLEADOR
    • Reglas ISR: ISR_DEDUCCIONES, ISR_RETENCION
  3. Asegurarse de que las reglas estén en el orden correcto:
    1. Primero las reglas base (BASE_IHSS, BASE_RAP, BASE_ISR)
    2. Luego las deducciones IHSS y RAP
    3. Después las deducciones ISR
    4. Finalmente la regla NET (si existe)
6 Configurar Reglas Salariales de Ingresos:

Para cada regla salarial que represente un ingreso (salario base, horas extra, bonos, etc.):

  1. Ir a la regla salarial
  2. En la pestaña "Honduras Configuration", marcar las casillas correspondientes:
    • IHSS Base: Si el ingreso debe incluirse en la base de cálculo de IHSS
    • RAP Base: Si el ingreso debe incluirse en la base de cálculo de RAP
    • ISR Base: Si el ingreso es gravable para ISR
    • Computable for Benefits: Si debe incluirse en el cálculo de 13° y 14° mes
  3. Seleccionar la periodicidad aplicable
Ejemplo: Para "Salario Base":
  • ✓ Marcar IHSS Base
  • ✓ Marcar RAP Base
  • ✓ Marcar ISR Base
  • ✓ Marcar Computable for Benefits
Para "Horas Extra":
  • ✓ Marcar IHSS Base
  • ✗ NO marcar RAP Base
  • ✓ Marcar ISR Base
  • ✗ NO marcar Computable for Benefits

5.2. Configuración de Empleados

7 Importar o Crear Empleados:

Menú: Honduras Payroll → Import Employees

Use el wizard de importación masiva o cree empleados manualmente.

8 Configurar Contrato del Empleado:

Menú: Empleados → Seleccionar Empleado → Pestaña "Honduras Payroll"

  1. Verificar que el empleado tenga un contrato activo en "Contract History"
  2. Si no existe, crear nueva entrada en "Contract History" con:
    • Fecha de inicio
    • Salario (wage)
    • Periodicidad (semanal/quincenal/mensual)
    • Puesto de trabajo
    • Departamento
9 Configurar Exclusiones (si aplica):

En la pestaña "Honduras Payroll" del empleado:

  • Marcar "Exclude from IHSS" si el empleado está excluido de deducciones IHSS
  • Marcar "Exclude from RAP" si el empleado está excluido de deducciones RAP
  • Marcar "Exclude from ISR" si el empleado está excluido de retenciones ISR
10 Configurar Conceptos Recurrentes (si aplica):

En la sección "Recurring Concepts" del empleado:

  • Agregar préstamos, anticipos, comisiones recurrentes, etc.
  • Configurar fechas de vigencia
  • Para préstamos, configurar monto total y número de cuotas

5.3. Generación de Nómina

11 Crear Batch de Nómina:

Menú: Nómina → Payslips → Crear

  1. Seleccionar la estructura salarial configurada
  2. Seleccionar el período de nómina (fecha desde/hasta)
  3. Seleccionar los empleados a incluir
  4. Crear los payslips
12 Calcular Nómina:

Para cada payslip o en lote:

  1. Abrir el payslip
  2. Hacer clic en "Compute Sheet"
  3. El sistema calculará automáticamente:
    • Bases de cálculo: Sumará todas las reglas marcadas como base (IHSS, RAP, ISR)
    • IHSS: Calculará IVM y EM según la configuración activa del empleado, respetando techos y exclusiones
    • RAP: Calculará FOVIIF y FRL según la configuración activa, respetando pisos, techos y exclusiones
    • ISR: Calculará deducciones y retención según la tabla ISR correspondiente a la periodicidad del empleado
    • Conceptos recurrentes: Aplicará automáticamente los conceptos recurrentes activos
13 Revisar Cálculos:

En el payslip, revisar la pestaña "Computation":

  • Verificar que las bases de cálculo sean correctas
  • Verificar que las deducciones IHSS, RAP e ISR sean correctas
  • Verificar que los techos y pisos se respeten
  • Verificar que el salario neto sea correcto

En la pestaña "Honduras Payroll Info" (si está disponible), revisar:

Campo Descripción
IHSS Base Base utilizada para cálculo IHSS
IHSS IVM Employee Aporte IVM del empleado
IHSS IVM Employer Aporte IVM del empleador
IHSS EM Employee Aporte EM del empleado
IHSS EM Employer Aporte EM del empleador
RAP Base Base utilizada para cálculo RAP
RAP FOVIIF Employee Aporte FOVIIF del empleado
RAP FOVIIF Employer Aporte FOVIIF del empleador
RAP FRL Employer Aporte FRL del empleador
ISR Taxable Base Base gravable para ISR (después de deducciones)
ISR Amount Monto de ISR retenido en este período
ISR YTD ISR acumulado año a fecha
Period Days Días del período de nómina
14 Confirmar Nómina:
  1. Una vez revisados todos los cálculos, hacer clic en "Confirm"
  2. El sistema generará automáticamente:
    • Asientos contables (si está configurado el módulo de contabilidad)
    • Registro en el historial de ISR (si aplica)
    • Actualización de saldos de préstamos/anticipos
15 Pagar Nómina:

Una vez confirmada, puede proceder con el pago según el proceso estándar de Odoo.

Información importante sobre los cálculos automáticos:
  • Techos IHSS: Se prorratean automáticamente según la periodicidad. Ejemplo: Techo mensual 11,903.13 → Techo quincenal = 11,903.13 × (15/30) = 5,951.57
  • Control de acumulados: Si hay múltiples nóminas en el mismo mes, el sistema controla los acumulados para respetar los techos mensuales
  • ISR acumulado: El sistema mantiene el historial de ISR y calcula la retención considerando lo ya retenido en el año
  • Exclusiones: Si un empleado está excluido de alguna deducción, las reglas correspondientes no se aplican
  • Configuración activa: El sistema usa automáticamente la configuración validada para el año y compañía del empleado

5.4. Proceso Mensual Recurrente

Una vez configurado todo, el proceso mensual es simple:

1 Crear batch de nómina para el período correspondiente
2 Calcular todos los payslips (el sistema aplicará automáticamente todas las deducciones)
3 Revisar cálculos (especialmente para empleados nuevos o con cambios)
4 Confirmar y pagar

6. Contabilidad

6.1. Configuración de Cuentas

En cada configuración (IHSS, RAP), en la pestaña "Accounting", asigne las cuentas contables correspondientes:

Cuentas IHSS

  • IVM Employee Account: Cuenta de pasivo para retenciones IVM de empleados
  • IVM Employer Account: Cuenta de gasto para aportes IVM del empleador
  • EM Employee Account: Cuenta de pasivo para retenciones EM de empleados
  • EM Employer Account: Cuenta de gasto para aportes EM del empleador

Cuentas RAP

  • FOVIIF Employee Account: Cuenta de pasivo para retenciones FOVIIF de empleados
  • FOVIIF Employer Account: Cuenta de gasto para aportes FOVIIF del empleador
  • FRL Employer Account: Cuenta de gasto para aportes FRL del empleador

6.2. Asientos Automáticos

Al confirmar la nómina, el sistema genera automáticamente asientos contables con las siguientes características:

  • Separación por componente: Líneas separadas para IVM, EM, FOVIIF y FRL
  • Separación empleado/empleador: Líneas distintas para deducciones del trabajador y aportes patronales
  • Cuentas configuradas: Usa las cuentas asignadas en las configuraciones
  • Soporte analítica: Si se usa analítica/centros de costo, se respetan en los asientos

8. Flujo de Trabajo Recomendado

1 Configuración Anual: Al inicio de cada año (o cuando cambien los parámetros oficiales):
  • Crear y validar configuración IHSS para el año
  • Crear y validar configuración RAP para el año
  • Crear y validar tablas ISR para el año (por periodicidad)
2 Configuración de Reglas: Revisar y actualizar reglas salariales marcando las bases correspondientes (IHSS, RAP, ISR, Computable).
3 Carga Inicial: Si es la primera vez:
  • Preparar archivo Excel con datos de empleados
  • Usar el wizard de importación
  • Revisar y corregir errores si los hay
4 Revisión de Contratos: Verificar que los contratos estén correctamente configurados con salarios y fechas de vigencia.
5 Conceptos Recurrentes: Configurar conceptos recurrentes (préstamos, anticipos, comisiones, etc.) para cada empleado que los tenga.
6 Procesamiento Normal: Procesar nóminas normalmente. El sistema calculará automáticamente todas las deducciones legales.
7 Revisión y Confirmación: Revisar los payslips generados, verificar cálculos y confirmar.
8 Décimo Tercer Mes: Al final del año (diciembre):
  • Crear registros de 13° mes para cada empleado
  • Calcular montos según método seleccionado
  • Incluir en nómina de diciembre
  • Marcar como pagado
9 Décimo Cuarto Mes: A mitad de año (junio):
  • Crear registros de 14° mes para cada empleado
  • El sistema calculará promedio/suma del primer semestre
  • Incluir en nómina de junio
  • Marcar como pagado
10 Auditoría: Usar los historiales (ISR History, Contract History) para auditorías y reportes.

9. Preguntas Frecuentes

¿Cómo se calcula el techo de IHSS para una quincena?

El sistema usa la regla estándar 30/360: TechoQuincena = TechoMensual × (15/30) = TechoMensual × 0.5

¿Qué pasa si hay múltiples nóminas en el mismo mes?

El sistema controla los acumulados del mes por empleado para asegurar que no se excedan los techos mensuales, evitando sobre-retención.

¿Puedo excluir a un empleado de alguna deducción?

Sí, en la ficha del empleado, pestaña "Honduras Payroll", puede marcar las exclusiones correspondientes (IHSS, RAP, ISR).

¿Cómo se calcula el 13° mes para empleados con salario variable?

Use el método "Variable" y el sistema calculará el promedio de los salarios del período trabajado basándose en los payslips generados.

¿Qué pasa si cambio el salario de un empleado a mitad de año?

Simplemente cree una nueva versión del contrato con la nueva fecha de inicio y salario. El sistema mantendrá el historial completo.
